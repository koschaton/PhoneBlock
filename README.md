# 🛡️ Prefix Call Blocker - Android App

แอปพลิเคชัน Android สำหรับดักและตัดสายเรียกเข้าอัตโนมัติตามเลขนำหน้า (Prefix) เช่น 6 ตัวแรก โดยตัดสายทันทีและ **ไม่แสดง Pop-up / ไม่สั่น / ไม่มีเสียงเตือน** เพื่อไม่ให้รบกวนเวลาเล่นเกมหรือใช้งานโทรศัพท์

---

## 📋 รายการเลขนำหน้าที่ตั้งค่าเริ่มต้นไว้ในระบบ
ระบบมาพร้อม 5 รายการเริ่มต้นที่บันทึกไว้ในฐานข้อมูลอัตโนมัติ:
1. `080070` (เบอร์มิจฉาชีพ/สแปม 080070xxxx)
2. `080071` (เบอร์มิจฉาชีพ/สแปม 080071xxxx)
3. `063863` (เบอร์มิจฉาชีพ/สแปม 063863xxxx)
4. `061272` (เบอร์มิจฉาชีพ/สแปม 061272xxxx)
5. `065349` (เบอร์มิจฉาชีพ/สแปม 065349xxxx)

*(ผู้ใช้สามารถกดเปิด/ปิดรายตัว หรือกดเพิ่มเลขใหม่และลบเลขที่ไม่ต้องการได้ผ่านหน้าจอแอปตลอดเวลา)*

---

## ⚡ ฟีเจอร์หลักของแอป
1. **ตัดสายระดับเสี้ยววินาทีก่อนหน้าจอสายเข้าเด้ง:** ใช้ `CallScreeningService` ของ Android ซึ่งตรวจสอบเบอร์ก่อนที่ระบบจะส่งสายไปยังหน้าจอโทรศัพท์
2. **ระบบ Normalize เบอร์อัจฉริยะ:** ตรวจสอบได้แม่นยำ ไม่ว่าเบอร์จะโทรเข้ามารูปแบบใด เช่น:
   - `0800701234`
   - `+66800701234` (แปลง +66 เป็น 0 อัตโนมัติ)
   - `080-070-1234`
3. **กล่องทดลองเบอร์ (Simulator Tester):** มีช่องให้พิมพ์ทดสอบเบอร์ในหน้าแอปได้ทันที เพื่อดูว่าหากมีเบอร์นี้โทรเข้ามา แอปจะตัดสายหรือไม่
4. **จัดการรายการเลขนำหน้า (Prefix CRUD):** เพิ่ม ลบ แก้ไข เปิด/ปิด Prefix ได้ไม่จำกัดจำนวน
5. **บันทึกประวัติการบล็อก (Block History):** บันทึกเบอร์ที่ถูกตัดสาย เวลา และ Prefix ที่ตรวจพบ
6. **สวิตช์เปิด/ปิดหลัก (Master Switch):** เปิดหรือปิดการทำงานของทั้งระบบได้ในคลิกเดียว

## 🚀 วิธีเปิดโปรเจกต์และสร้างไฟล์ APK ด้วย Android Studio

### 1. เปิดโปรเจกต์ใน Android Studio
1. เปิดโปรแกรม **Android Studio**
2. เลือก **File -> Open...**
3. เลือกโฟลเดอร์โปรเจกต์นี้: `C:\xampp\htdocs\phone`
4. รอให้ Android Studio ทำการ Sync Gradle ให้เสร็จสมบูรณ์

### 2. สร้างไฟล์ติดตั้ง (Build APK)
- ไปที่เมนูด้านบน: **Build -> Build Bundle(s) / APK(s) -> Build APK(s)**
- เมื่อสร้างเสร็จ Android Studio จะขึ้นแจ้งเตือน `locate` ให้กดเพื่อดูไฟล์ APK ที่สร้างขึ้นในโฟลเดอร์:
  `app/build/outputs/apk/debug/app-debug.apk`

### 3. ติดตั้งและเปิดใช้งานบนมือถือ
1. ส่งไฟล์ `app-debug.apk` ไปติดตั้งบนโทรศัพท์ Android ของคุณ (หรือเสียบสาย USB แล้วกดปุ่ม Run สีเขียวใน Android Studio)
2. เมื่อเปิดแอปครั้งแรก แอปจะขึ้นหน้าต่างขอสิทธิ์ **"Caller ID & Spam App" (แอปคัดกรองสายและสแปม)** ให้กดยืนยัน **"ตั้งเป็นค่าเริ่มต้น" (Set as default)**
3. ระบบจะเริ่มทำงานเงียบๆ ในพื้นหลังทันที เมื่อมีเบอร์ที่ขึ้นต้นด้วยเลขในรายการโทรเข้ามา สายจะถูกตัดทิ้งเป็นสายไม่ว่างทันทีโดยไม่เด้งขึ้นหน้าจอขณะเล่นเกม
